# Studies

Three standalone interaction studies. Each folder has an `index.html` you can
open directly in a browser, a `README.md` with run instructions, and a
`STUDY.md` describing its components, states and code locations.

| Study | Folder | Interaction |
| --- | --- | --- |
| Press Me Button | [`press-me-button/`](press-me-button/) | Press a round button; it latches down with a check mark. |
| Flip the Switch | [`flip-the-switch/`](flip-the-switch/) | Flip a toggle switch from OFF to ON; a light turns on. |
| Enter the Code | [`enter-the-code/`](enter-the-code/) | Type the 4-digit code `1234` on a keypad. |

These are the building blocks for a connected sequential interaction prototype.
